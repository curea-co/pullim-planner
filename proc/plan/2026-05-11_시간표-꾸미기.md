# 시간표 꾸미기 (Decorate) — 레이아웃 템플릿 + 색상 팔레트

## 목표

`/planner/manage`에서 사용자가 **활성/비활성 모든 플래너**에 대해 **레이아웃 템플릿(공스타그램 기반 시각 스타일)** 과 **색상 팔레트 테마**를 고를 수 있고, 선택 즉시 간소화된 미리보기에 반영되며, 저장하면 해당 플래너의 시간표 렌더링에 적용된다.

## 사용자 확정 사항

- 진입점: `/planner/manage` 안 통합 (페이지 분리 X)
- 템플릿 = **공스타그램 기반 시각 레이아웃 4종** (뷰 타입과 별개. 추후 확장 전제)
- 색상 = 사전 정의 팔레트 테마 7종 중 1개. 블록 타입별 색은 팔레트가 자동 매핑 (개별 지정 X)
- 색상 표현은 **hex 문자열 직접 사용** (CSS 변수 확장 X — 빠른 속도 우선)
- 미리보기는 선택한 플래너의 실제 데이터를 축소해 사용
- **비활성 플래너도 편집 가능** — 꾸미기 섹션이 플래너 picker로 컨텍스트 전환

## 레이아웃 템플릿 4종 (공스타그램 기반)

공스타그램(한국 학습 인스타그램) 50장 분석에서 자주 보이는 시각 유형을 4종으로 정리. 모두 *일간 데이터*를 다르게 그려내는 변형이며, 주간·월간 뷰는 템플릿과 독립적으로 동작 (MVP 범위).

1. **세로 타임라인** (`vertical_timeline`) — 좌측 시간 라벨 + 우측 24h 셀 블록. 현 `SideTimeline24` 스타일. 형광펜 막대 느낌. **디폴트.**
2. **체크리스트** (`checklist`) — 시간 + 활동명 한 줄씩, 좌측 색 점 + 체크박스. 다이어리·불릿저널 느낌.
3. **블록 카드 스택** (`block_cards`) — 시간 비율 무시, 일정마다 큰 카드 1개. 카드 좌측 색띠 + 상단 시간 + 본문 + 상태 배지. 트렐로/노션 느낌.
4. **파이 + 리스트** (`pie_list`) — 상단 도넛 차트(블록 타입별 시간 비중) + 하단 컴팩트 리스트. 통계+요약 느낌.

> 추후 확장: 격자 시간표(학교 시간표 스타일), 캘린더 위클리, 핸드라이팅 폰트 변형 등.

## 설계

### 1. 데이터 모델 (`src/lib/mock/planner.ts`)

```ts
type Planner = {
  // ...기존 필드
  customization?: {
    layoutId: LayoutTemplateId;  // 'vertical_timeline' | 'checklist' | 'block_cards' | 'pie_list'
    paletteId: PaletteId;
  };
};
```

- `customization` 없으면 `{ layoutId: 'vertical_timeline', paletteId: 'pullim_blue' }`로 폴백 → 기존 동작 무변경
- 시드 3건에 각기 다른 디폴트 부여 (탐색용)
- 뷰 타입(day/week/month)은 *customization과 무관* — 기존 `?view` 라우팅 그대로

### 2. 레이아웃 템플릿 시스템 (`src/lib/tokens/layout-templates.ts` 신설)

```ts
export type LayoutTemplateId = 'vertical_timeline' | 'checklist' | 'block_cards' | 'pie_list';
export type LayoutTemplate = {
  id: LayoutTemplateId;
  label: string;          // '세로 타임라인'
  description: string;    // '좌측 시간축 + 우측 색 블록. 공스타그램 클래식.'
  thumbnail: () => ReactNode;  // 컨트롤 패널 미니 썸네일 (SVG/CSS)
};
export const layoutTemplates: Record<LayoutTemplateId, LayoutTemplate>;
export const defaultLayoutId: LayoutTemplateId = 'vertical_timeline';
```

각 템플릿의 실제 렌더 컴포넌트는 별도 위치:
- `src/components/planner/layouts/vertical-timeline.tsx` — 기존 `SideTimeline24` 래핑/리유즈
- `src/components/planner/layouts/checklist.tsx` — 신설
- `src/components/planner/layouts/block-cards.tsx` — 신설 (`block-card.tsx` 리유즈 가능)
- `src/components/planner/layouts/pie-list.tsx` — 신설 (도넛 차트 + 리스트)

공통 인터페이스: `(props: { blocks: TimeBlock[]; paletteId?: PaletteId; compact?: boolean }) => JSX.Element`

### 3. 팔레트 시스템 (`src/lib/tokens/palettes.ts` 신설)

```ts
export type PaletteId = 'pullim_blue' | 'forest' | 'sunset' | 'pastel' | 'mono' | 'mint' | 'rose';
export type Palette = {
  id: PaletteId;
  label: string;
  emoji?: string;
  block: Record<BlockType, string>;  // hex 문자열
};
export const palettes: Record<PaletteId, Palette>;
export const defaultPaletteId: PaletteId = 'pullim_blue';
export function getBlockColor(type: BlockType, paletteId?: PaletteId): string;
```

- 7개 팔레트 모두 hex (`#3B6FF6` 등) 직접 정의. CSS 변수 확장 X.
- `pullim_blue` = 현 `blockTypeMeta.colorVar`의 *해석된 hex값* (`pullimBlue` 토큰에서 추출) → 디폴트 시 무변경
- `getBlockColor(type)` 인자 미지정 = 디폴트 팔레트

모든 `blockTypeMeta[type].colorVar` 직접 참조를 `getBlockColor(type, paletteId)` 호출로 교체.

### 5. 꾸미기 섹션 (`src/components/planner-manage/decorate-section.tsx` 신설)

`/planner/manage` 페이지 PageHeader 아래, 카드 그리드 위에 세로 스택.

#### 구조

```
┌─ 꾸미기 ──────────────────────────────────────┐
│ 어떤 시간표를 꾸밀까요?                          │
│ [● 6월 모의평가 (활성)] [○ 1학기 기말] [○ 4월 학평] │ ← planner picker (탭/세그먼트)
├──────────────────────────────────────────────┤
│ ┌─ 미리보기 (~280px) ─┐  ┌─ 컨트롤 ────────┐ │
│ │   선택 중인 템플릿+ │  │ 레이아웃 (4종)    │ │
│ │   팔레트 실시간     │  │ [📊][✓][🗂][🥧]│ │
│ │   반영              │  │                  │ │
│ │                    │  │ 팔레트 (7종)     │ │
│ │                    │  │ [🌊][🌲][🌅]    │ │
│ │                    │  │ [🌸][⚫][🌿][🌹]│ │
│ │                    │  │                  │ │
│ │                    │  │ [되돌리기][저장] │ │
│ └────────────────────┘  └──────────────────┘ │
└──────────────────────────────────────────────┘
```

#### 동작

- **플래너 picker**: 세그먼트 컨트롤 (또는 가로 스크롤 탭). 활성 플래너가 기본 선택. 아카이브된 플래너는 picker에서 제외 (또는 마지막에 흐리게).
- **미리보기**: 선택된 플래너의 mock 데이터(예: 활성=`todayBlocks`, 비활성=각 플래너용 대표 샘플 또는 동일 `todayBlocks` 재사용)를 4개 layout 컴포넌트 중 1개로 렌더. `compact: true`로 축소 렌더.
  - MVP: 비활성 플래너도 `todayBlocks`를 그대로 사용해 미리보기 (실제 일정이 다르더라도 스타일 미리보기 용도는 충분). 별도 mock 추가는 follow-up.
- **레이아웃 컨트롤**: 4개 라디오 카드. 각 카드는 `LayoutTemplate.thumbnail()` 미니 그림 + 라벨.
- **팔레트 컨트롤**: 7개 스와치. 각 스와치 = 4개 색 도트 미니 + 라벨.
- **로컬 state**: `{ layoutId, paletteId }` — picker 변경 시 해당 플래너의 저장값으로 reset.
- **저장**: `updatePlannerCustomization(selectedPlannerId, { layoutId, paletteId })` → toast 성공. `isDirty=false`.
- **되돌리기**: 저장값으로 로컬 state 복귀.
- `isDirty=false`면 두 버튼 disabled.

#### 컨트롤 카드 메뉴 통합

[planner-card.tsx](src/components/planner-manage/planner-card.tsx)의 케밥 메뉴에 "**🎨 꾸미기**" 액션 추가 → 꾸미기 섹션의 plannerId를 그 플래너로 전환 + 페이지 상단으로 스크롤 (앵커 또는 ref scrollIntoView).

### 6. mock helper

`src/lib/mock/planner.ts`에 추가:
```ts
export function updatePlannerCustomization(
  id: string,
  customization: NonNullable<Planner['customization']>,
): Planner
```
- 시드 mutate (`activatePlanner` 등과 동일 패턴), `updatedAt` 갱신

### 7. 저장 효과

- *팔레트* — `usePlannerCustomization(id)` 훅이 자동 반영 → 홈·플래너·매니지 미리보기 모두 동시 갱신 (활성 플래너 기준).
- *레이아웃* — `/planner?view=day` 진입 시 활성 플래너의 `layoutId`를 읽어 해당 layout 컴포넌트로 swap. `?view=week|month`는 영향 없음 (기존 그대로).
  - 변경 위치: [src/app/(student)/planner/page.tsx:143](src/app/(student)/planner/page.tsx#L143) `{view === 'day' && <DayView />}` 부분을 `<DayViewWithLayout />` 또는 `DayView` 내부에서 layoutId 분기.
