# 11. 풀림 플래너 — 도메인 디자인 시그니처

풀림 플래너만의 사적(domain-private) 디자인 결정을 정리한다. 일반 디자인 시스템([08-design-system.md](08-design-system.md))과 마이크로카피([07-branding.md](07-branding.md)) 위에 얹는 **도메인 레이어**.

- 권위 입력: [input/design-system/private-planner.md](../../input/design-system/private-planner.md), [input/planner/REPORT.md](../../input/planner/REPORT.md)
- 권위 핸드오프: [input/docs-archive/08_풀림_플래너_핸드오프.md](../../input/docs-archive/08_풀림_플래너_핸드오프.md)
- 작성 일자: 2026-05-19

> **문서 위치**: 풀림 플래너의 정체성은 **"수능까지 남은 시간을 시각·감정·진행도로 동시에 보여주는 학생용 학습 OS"**. 일반 캘린더가 무난한 패턴이라도 학생 수험 도메인에선 다른 결정을 내려야 한다 — "충돌"은 회의실이 아니라 **체력·집중 한계**이고, "빈 슬롯"은 free time이 아니라 **회복 vs 보강의 갈림길**.

---

## 1. 블록 상태 색문법 (5단)

학습 블록 카드와 일과 캘린더 그리드는 동일 색 문법을 공유한다. 청색 농도 변화만으로 의미 구분하던 옛 디자인을 **5단 상태 색문법**으로 통일.

| 상태 | 면 색 | 시그니처 패턴 | 의미 |
|---|---|---|---|
| **완료** | success-bg `#E6F7EE` | 좌측 4px stripe `success-strong #0E8C56` + 우측 ✓ 체크 아이콘 | 블록 정상 종료 |
| **진행 중** | brand-50 `#EEF3FF` | 좌측 4px stripe `brand-600 #2854D8` + 우측 진행 wedge (예: 60%) + outline 강조 | 현재 active 블록 |
| **대기 (미래)** | white | 1px `brand-100 #DCE6FF` border, stripe 없음 | 시작 전 |
| **미수행 (이월)** | warn-bg `#FEF3DB` | 좌측 4px stripe `warn-cta-bg #D97706` + ⚠ + amber 사선 빗금 | 시간 지난 미실행 |
| **회복 / 식사** | slate-100 `#EDF0F5` | pill radius + 🍽 / 🛌 아이콘, stripe 없음 | 비학습 시간 |

> "진한 파랑 = 진행 중", "사선 = 이월", "녹색 = 완료", "회색 = 비학습"의 **4단어 문법**이 한눈에 잡혀야 한다. 청색 농도만으로 대기 vs 완료를 구분하던 패턴은 금지.

### 1.1 진행 wedge

진행 중 블록은 카드 우측에 **진행률 wedge**를 표시:

```
┌══════════════════════════════════════════════════┐
│▐18:25 ✎  미분 — 적응형 문제 풀이      ●●●●○○ 60%│
│  D-day 빈출 가중 · 남은 12분            [이어서] │
└══════════════════════════════════════════════════┘
```

- 5~10개 dot 또는 percentage. 캘린더 그리드 안에서는 가로 fill bar로 단순화.
- 60% 같은 비주얼 진행은 학생이 "이어서"가 어디서부터인지 즉시 파악하도록 함.

### 1.2 카피 정합

상태별 라벨은 [07 § 4.5.2 위협→권유 교체표](07-branding.md#452-위협--권유-교체표)에 따른다:
- ❌ "미수행" → ✅ "이월"
- ❌ "실패" → ✅ "어제 못한 30분, 오늘로 이월했어요"

## 2. D-day Tier 시스템 (5단계)

D-day는 단순 카운트가 아니라 **학생 행동을 다르게 유도하는 시각 등급**이다.

| Tier | 범위 | 시각 처리 | 톤 |
|---|---|---|---|
| 평시 | D-31+ | 본문 inline 텍스트 "D-45" | 무채색 |
| 주의 | D-15 ~ D-30 | `brand-600` 알약, 굵게 | 차분한 강조 |
| 임박 | D-7 ~ D-14 | `warn-cta-bg` 알약 + 캘린더 아이콘 | 주의 환기 |
| 직전 | D-1 ~ D-6 | `danger` 알약 + 좌측 미세 pulse 모션 (opacity 0.8↔1.0, 2초 주기) | 권유형 임박 |
| 당일 | D-0 | `danger` 솔리드 + "오늘 D-Day" 텍스트 + **헤더 4px warning 띠** | 모든 화면에 헤더 띠 |

### 2.1 D-3 이내 헤더 띠

D-3 이내일 때 페이지 최상단 헤더 아래에 **4px 두께 띠** (warn-cta-bg 색). 띠 위 호버 시 툴팁:

> "6월 모의평가까지 3일 — 컨디션 75% 이상 유지하기"

명시적 임박 상태 신호. 모든 페이지에 적용.

### 2.2 학습 블록 ↔ 시험 연결 칩

블록 카드 상단에 작은 outlined 칩: `🎯 6월 모의평가 가중`. 클릭하면 동일 시험에 묶인 블록 필터링. 메타 텍스트 "D-day 빈출 가중"이 시각적 칩으로 격상.

### 2.3 카운트다운 미니 뷰 (헤더 우측 상시)

`AppHeader` 우측에 현재 스트릭 칩(`🔥 17일 연속`) 옆에 **가장 가까운 시험 D-day 칩** (`D-16 6월 모의평가`) 상시 노출. 어디 페이지에 있든 시야 안에 시험 일정.

### 2.4 카피 톤

[07 § 4.5.1 4원칙 — 위협→권유](07-branding.md#451-플래너-카피-4원칙-학생-페르소나-톤) 적용. 임박은 위협이 아니라 **자율감으로 프레이밍**:

> "D-3 — 컨디션 안정 우선, 새 단원 No"

## 3. 컨디션 vs 번아웃 메타 분리

두 메타는 **다른 축**임을 시각·카피로 명시한다.

| 메타 | 정의 | 입력 | 색 문법 |
|---|---|---|---|
| **컨디션** | 오늘의 주관 감정 | 5단 이모지 (😴😫🙂😊🤩) | 무채색 + 이모지 색 |
| **번아웃 안전도** | 연속·누적 부담의 *역수* (객관) | 시스템 계산 0-100 (**높을수록 안전**) | 0-49 danger / 50-69 warn / 70+ success |

> **번아웃 안전도**: `todayBurnout.score` 값은 "안전도"로 해석한다 — 점수가 높을수록 부담이 적어 안전. 코드(`src/lib/mock/planner.ts:229`)의 시맨틱과 정합. UI에서는 `🔋 안전도 64` 로 노출 (단순 "번아웃 64"는 양방향 해석 가능해 금지).

### 3.1 헤더 노출

옛 디자인의 `🙂 오늘 컨디션 · 번아웃 — 보통이에요 · 64/100` 한 줄 표기는 **금지**. 두 칩으로 분리:

```
🙂 오늘 보통    🔋 안전도 64 · 주의
```

### 3.2 임계치 권유 배너

**안전도 < 50** (위험) 또는 컨디션 연속 2일 "피곤" 시 메인 헤더 위 1줄 배너 (warn-bg, dismissible):

> 이번 주 부담이 쌓이고 있어요. 오늘 저녁 1블록 줄여볼까요?
> `[블록 줄이기]` `[그대로 가기]` `[부모님께 공유]`

**위협이 아니라 선택지를 제공하는 권유형**. [07 § 4.5.2 교체표](07-branding.md#452-위협--권유-교체표) 적용.

### 3.3 "부모님께 보내기" 동선

- 리포트 페이지 우상단 (기존) + **임계치 권유 배너 안 secondary 액션** (추가).
- 학생 톤 → 정중한 톤: "부모님께 보내기" → **"부모님께 이번 주 회고 공유"**.

### 3.4 컨디션 입력 픽커 — emoji 허용

5단 이모지 픽커는 [08 § 14.1.1 예외 1](08-design-system.md#1411-아이콘-일관성-예외-emoji-허용-영역)에 해당. `conditionMeta` (`src/lib/mock/planner.ts`)가 권위.

## 4. 시간 그리드 (일과 캘린더)

### 4.1 가변 행 높이 — 시간대 그룹

11시간을 균일 분할하지 않고 **3개 학습 시간대**로 그룹화:

| 그룹 | 시간 | 행 단위 | 배경 |
|---|---|---|---|
| 점심 | 12-14 | 80px | "휴식 권장" 약한 배경 (slate-50) |
| 오후 집중 | 14-18 | 120px | white (무배경) |
| 저녁 코어 | 18-22 | 160px | 약한 강조 배경 (brand-50 40%) |

좌측에 그룹 라벨 sticky로 깔아 "지금이 코어 타임"이라는 메타 인식 무료 제공.

### 4.2 "지금" 인디케이터

현재 시각 가로선을 **단순 빨간 선에서 알약 라벨로 강화**:

- 라인 양 끝에 작은 알약 `● 14:03 지금` (좌측 시간 라벨 컬럼에 살짝 돌출)
- 60초마다 부드럽게 한 픽셀씩 내려가는 micro-motion (1000ms standard easing, 60초 간격)
- 라인 색은 채도 한 단계 낮춤. 대신 라인 좌측에 두꺼운 dot(8px)로 강조.

### 4.3 빈 슬롯 affordance

호버 시:
- 슬롯 배경 transparent → slate-50 (150ms standard)
- 점선 border 추가
- 중앙에 ghost 버튼 2개: `+ 15분 회복` / `+ 25분 보강` (translateY 8→0 + fade-in)

빈 슬롯이 30분 이상이면 시스템이 회복/보강 제안 미리 채워둠 (얇은 점선 카드).

### 4.4 충돌·겹침 표현

- 같은 시간대 2개: 50%씩 가로 분할 + 양쪽 카드 우상단 `⚠ 충돌` 노란 dot
- 부분 겹침: 뒤 블록을 5px 우측 indent + 좌측 상단에 연결 곡선

### 4.5 드래그·리사이즈 어포던스

"곧 열려요" 문구 제거 (회귀 사례 — input/REPORT § 6). 대신 카드 hover 시 좌우 끝 8px 영역에 grip 아이콘 fade-in. 베타 출시 전까진 카드 우상단에 `Beta` 작은 칩 (chip pattern).

## 5. 학습 블록 카드 시스템

### 5.1 블록 타입별 아이콘 컨테이너

| 타입 | 컨테이너 radius | 아이콘 (lucide) | 면 색 |
|---|---|---|---|
| 모의평가 | 14px 정사각 | TrophyIcon | warn-bg `#FEF3DB` |
| 문제풀이 | 14px 정사각 | EditIcon | brand-50 `#EEF3FF` |
| 단어/암기 | 14px 정사각 | BookOpenIcon | violet-50 (브랜드 보조색 — 신설 필요) |
| 개념 학습 | 14px 정사각 | LampIcon | teal-50 (신설 필요) |
| 식사/회복 | pill | UtensilsIcon / CoffeeIcon | slate-100 |

> **violet-50 / teal-50 토큰 추가는 후속 plan**. 우선 brand-50로 폴백.

모의평가 컨테이너에는 작은 **D-day 칩 (`D-16`)**을 우상단에 겹쳐 "이 블록이 그날까지 가장 중요"임을 시각화.

### 5.2 점3개 메뉴 — 상태별 차별화

| 상태 | 메뉴 항목 |
|---|---|
| 이월 (미수행) | `지금 시작` / `내일로 미루기` / `삭제` |
| 진행 중 | `일시 정지` / `메모 추가` |
| 완료 | `되돌리기` / `회고 보기` |
| 대기 | `지금 시작` / `시간 변경` / `노트` |

옛 디자인은 모든 행에 동일 메뉴 — 학생 부담 증가. 상태머신에 맞춰 분기.

### 5.3 정렬 모드 토글

`오늘의 학습 블록` 헤더 우측에 sort 아이콘 + 라벨:
- 기본: **시간순**
- 옵션: **우선순위순** (연체·D-day 가중 위로) / **코스트순** (짧은 것부터)

### 5.4 카드 hover micro-motion

0.18s ease-out (= 200ms standard easing 근사)으로:
- `translateY(-1px)` + shadow-sm 부여
- 좌측 stripe가 1px 두꺼워짐

클릭 어포던스 신호.

## 6. 주간 성장 리포트 — 인사이트 카드

KPI 카드 4개와 차트 위주의 옛 디자인에 **자동 생성 인사이트 카드** 슬롯을 신설.

### 6.1 인사이트 카드 (한 주 3~5개)

리포트 상단에 카드 슬롯:

| 예시 카피 | 액션 칩 |
|---|---|
| 📈 수학 정답률 +12% — 새 단원 진입 적기 | `[시간표 조정]` |
| ⏱ 화요일 학습 시간 짧았어요 — 평일 시간대 점검 | `[시간표 조정]` |
| 🔋 금요일 부담 신호 — 토요일 30분 줄여볼까요? | `[블록 줄이기]` |
| 💪 17일 연속 1블록 이상 완료 — 흐름 유지 | — |

세 줄 이내 짧은 카피 + 작은 액션 칩. 학생이 처음 보는 화면이 **"데이터 덤프"가 아니라 "선생님 멘트"**.

카피 톤은 [07 § 4.5.1 4원칙](07-branding.md#451-플래너-카피-4원칙-학생-페르소나-톤) 준수 — 평가어 금지·관찰어 사용.

### 6.2 KPI 카드 sparkline

각 KPI에 16px 높이 sparkline (7일) + 자동 인사이트 한 줄:

```
┌─ 학습 시간 ────────────┐
│ 29.3h    ↑ 4h         │
│ /30h 목표             │
│ ▁▂▃▅▆▇▆ (sparkline 7일)│
│ 화 부족 → 토 보강 ✓    │
└────────────────────────┘
```

카드 hover → 드릴다운 모달.

### 6.3 차트 컬러 다양화

옛 디자인 단조 청색 5계열 → 메트릭별 의미 색:
- 학습 시간 막대: `brand-500` / `brand-200` (목표 미달 = 옅음)
- 정답률 라인: `success-strong #0E8C56`
- 컨디션 trend: 이모지 색 + 옅은 청색 막대
- 번아웃 안전도: 임계치 색 (green/amber/red)
- 약점 단원 진도: 진도 % 기반 (0-30 slate / 30-70 brand / 70+ success)

### 6.4 회고 한 줄 작성 UI

KPI 영역 아래 `이번 주 한마디` 카드 — 빈 칸 placeholder "이번 주 가장 뿌듯한 한 순간". 자동 저장. 4주 누적 시 월간 리포트에 인용.

## 7. 온보딩 — 마법사형 흐름

옛 `/planner/onboarding`은 "기능 설명서" 톤. **신규는 4단계 마법사**.

```
1. 인사 + 목표 시험 선택 (수능 / 모의평가 / 내신)
2. D-day 입력 → 자동 계산 "오 16일 남았어요" 인사이트
3. 평일/주말 학습 가능 시간 슬라이더 (예: 평일 18-22, 주말 10-18)
4. 자동 생성된 첫 1일 미리보기 + [이대로 시작] / [조정]
```

각 단계에 progress bar 상단 (0/4 → 4/4). 우측에 mock 카드 실시간 반영 — 학생이 **"내가 입력한 것이 화면을 바꾼다"**를 체험.

### 7.1 첫 블록 완료 celebration

온보딩 후 첫 블록 완료 시:
- 입자 confetti 8~12개 방사상 (300ms standard easing)
- 헤더 스트릭 칩 1.3× bounce (emphasis easing)
- Toast: `첫 블록 완료! 풀림이 학습 패턴을 학습하기 시작했어요`

**이 한 순간이 retention의 90%** ([input/private-planner.md § 7](../../input/design-system/private-planner.md)).

### 7.2 명칭 분리

- `/planner/onboarding` → 첫 사용자 4단계 마법사 (강제 진입)
- `/planner/guide` → 언제든 찾아보기 (옛 콘텐츠)

> 명칭 변경은 후속 plan. 본 spec은 의도 정의만.

## 8. 플래너 시그니처 모션 카탈로그

[08 § 10 모션 토큰](08-design-system.md#10-모션--애니메이션) 위에 얹는 플래너 고유 모션 8가지.

| ID | 트리거 | 변화 | duration / easing |
|---|---|---|---|
| **M1** 현재 시각 라인 자동 흐름 | 시계 1분 진행 | 빨간 가로선 1px 부드럽게 아래로, 좌측 알약 숫자 fade-update | 1000ms standard, 60초 간격 |
| **M2** 블록 완료 체크 | 블록 100% / [완료] 클릭 | stripe blue→green 그라데이션, ✓ stroke-draw, 카드 1px 위로 살짝 뜸 | 400ms `cubic-bezier(0.34, 1.56, 0.64, 1)` (overshoot) |
| **M3** 컨디션 이모지 탭 | 5단 이모지 중 하나 탭 | 탭된 이모지 1.15× 확대 + -5°→0° bounce, 나머지 0.5 fade, 0.6s 후 fold + toast | 250ms spring(stiffness 400, damping 22) |
| **M4** D-day 칩 펼침 | hover / tap | `D-16` → `D-16 · 6월 모의평가 · 5/24(토)` 가로 확장. D-3 이내일 때 pulse 추가 | 펴짐 180ms ease-out, 닫힘 120ms ease-in, pulse 2초 주기 |
| **M5** 시간대 그룹 sticky | 캘린더 내부 스크롤 | 그룹 헤더("저녁 코어") 상단 sticky, 다음 그룹 진입 시 위로 밀려나감 | native sticky + 16ms throttle |
| **M6** 빈 슬롯 affordance | 빈 슬롯 hover | 배경 slate-50, 점선 border, ghost 버튼 2개 8px translateY + fade-in | 150ms standard easing |
| **M7** 인사이트 카드 stream-in | 리포트 페이지 진입 | 카드 3-5개 좌→우로 50ms 시차 fade-in + translateY(8→0) | 300ms standard, 50ms stagger |
| **M8** 스트릭 마일스톤 confetti | 7/14/30/100일 도달 또는 첫 블록 완료 | 입자 8-12개 300ms 방사상, 헤더 칩 1.3× bounce + toast | 입자 300ms standard, 칩 spring(stiffness 500, damping 18) |

`prefers-reduced-motion: reduce` 시 모든 M1~M8 effective duration = 0 ([08 § 10.2](08-design-system.md#102-easing-토큰)).
