# Pullim Planner — 디자인/레이아웃/UI/UX 관찰 리포트

- 대상: https://pullim-planner.vercel.app/planner
- 일자: 2026-05-19
- 방법: Playwright(Chromium) + getComputedStyle 토큰 추출. 데스크탑 1440×900, 모바일 390×844 ko-KR.
- 산출물 위치: `/tmp/pullim-audit/planner/`

> **중요한 정정**: 사용자 메모에는 "학원 운영자(원장/강사)용"으로 적혀 있었으나, 실제 화면은 **학생용 학습 플래너**(수능 D-day 기반, 모의평가/단어/문제풀이 블록 관리)였습니다. 컨디션·번아웃 트래커, "부모님께 보내기" 버튼 등이 학생/학부모 사용자 모델을 뒷받침합니다.

## 1. 첫인상 & 정보 구조

랜딩 1–3초 안에 보이는 것: 좌측 사이드바(풀림 플래너 · 홈/시간표 관리/성장 리포트/소개하기), 상단 헤더(로고·17일째 연속 뱃지·검색·알림·아바타), 메인 영역의 H1 "오늘의 학습 — 4월 24일 목요일" + 메타라인(6월 모의평가 · D-16 · 1/7 블록 완료), 그 아래 좌측 "오늘 일과" 타임라인 카드와 우측 "오늘의 학습 블록" 리스트.

- **정보 계층 양호**: H1 24px, 캡션 12px, 본문 16px가 충분히 구분됨.
- **메인 액션 명확**: 우측 시간 라인의 현재 블록("이어서") + 좌측 "다음 블록 — 지금 시작" CTA가 명시적.
- **약점**: 메타라인 "6월 모의평가 · D-16 · 1/7 블록 완료"가 모두 같은 청색 굵은 글씨라 D-16(가장 중요한 정보)이 시각적으로 묻힘. "(데모)" 라벨이 있어 실서비스 상태 모호.

## 2. 레이아웃

- 데스크탑: 230px 좌 사이드바 + 중앙 메인(약 900–1000px). 1440 폭에서 우측 여백이 과도하게 큼(약 240px). max-w가 작아 보임.
- 좌우 2열 그리드(오늘 일과 30~35% / 학습 블록 65~70%). 균형 OK.
- **모바일 치명적 이슈**: 헤더 아래 약 250px 분량의 **거대한 빈 공간**이 존재. 본문이 한참 아래에서 시작됨(스크롤 없이는 H1만 겨우 보임). data attribute나 페이로드 placeholder가 빈 채로 자리 잡은 것으로 추정.
- 하단 탭바(홈·관리·리포트·소개) 4개로 사이드바 메뉴와 1:1 일치. 일관성 좋음.

## 3. 타이포그래피

- 폰트: **Pretendard Variable** (좋은 선택). 한글 가독성 양호.
- 크기 스케일이 **너무 잘게 쪼개짐**: 9, 10, 11, 12, 12.5, 14, 16, 24px 8단계. 9~10px는 데스크탑에서도 거의 안 보일 정도로 작음(예: 캘린더 12·13·14 시각 라벨).
- H2/H3가 본문과 동일한 16px라서 헤딩 위계가 약함. "오늘의 학습 블록"(H2)·각 블록 제목(H3)·본문이 같은 사이즈/굵기 차이만으로 구분.
- 12.5px 같은 비정수 값이 잡힌 것은 토큰 정의 누락으로 보임.

## 4. 컬러 & 톤

- 정의된 CSS 변수는 **다크 테마**(`--background:#080b18`, `--card:#121627`)이나 **실제 화면은 라이트 톤**. 변수가 적용 안 됨 → 다크모드 토글이 있어도 동작 안 할 가능성 또는 죽은 코드.
- 실사용 팔레트: 청색 단일 브랜드 강세. `#3B6FF6 / #2854D8 / #1D3FA8`(primary 계열), 슬레이트 그레이 스케일, 매우 절제된 시멘틱 컬러(완료=#12B26B, 경고=#F59E0B, 위험=#E5484D, 미수행 amber 뱃지).
- 다크모드: 토글 없음(UI상). CSS만 준비된 미완성 상태로 추정.
- 차트 색상 5개가 모두 청색 계열 단일 색조 명도 변형 — 컬러풀 강세 없는 차분한 톤이지만 다중 시리즈 구분이 약함.

## 5. 컴포넌트

- 버튼: primary(파랑 fill), ghost(텍스트만, hover slate-50), 작은 액션 뱃지(시작/이어서/대기/완료). **"시작" 버튼이 11px 폰트 + 4px 세로 padding으로 매우 작음**.
- 카드: 라운드 14px, 1px solid border, 매우 옅은 그림자. 카드 안에 카드(중첩) 다수.
- 탭: pill(일간/주간/월간) — 활성 탭은 흰색 배경+청색 텍스트, 비활성은 회색. 명확.
- 시간표 캘린더: 12~22시 세로 그리드 + 가로 블록바(파랑 농도 다름). 시간 라벨 작고 현재 시각 가로선(빨강) 효과적.
- 학습 블록 리스트: 시각·아이콘·제목·서브·상태뱃지·CTA·점3개. 정보 밀도 OK, 다만 우측 끝 점3개 메뉴가 페이지마다 일관 위치인지 확인 필요.
- 아바타: 한글 한 글자("서") 단색 청 원형. 단순하지만 군더더기 없음.
- 컨디션 트래커: 이모지(🙂) + 슬라이더 점수(64/100). 살짝 가벼운 톤이 학생 사용자엔 적합.

## 6. 인터랙션 & 모션

- 정적 캡처상 hover/focus 토큰은 정의되어 있음(focus ring `0 0 0 4px rgba(59,111,246,0.15)`). 사이드바·버튼 hover 색 잘 설계됨.
- "드래그 정렬 곧 열려요" 문구 — 미구현 기능을 미리 안내. 사용자 입장에서는 살짝 어색(왜 안 되는데?).
- 헤더 `backdrop-blur-md` 사용 — sticky 헤더에서 자연스러움.

## 7. 마이크로카피 & 한국어 UX

- 톤: **존댓말 + 다정한 표현** ("드래그 정렬 곧 열려요", "보통이에요", "지금 시작", "이어서"). 학생 대상에 적절.
- "오늘의 학습 — 4월 24일 목요일" em-dash 사용 OK.
- "(데모)" 라벨이 자주 보임 — 라이브 서비스라면 거슬릴 수 있음.
- 빈상태/오류 메시지는 캡처 안 됨.
- "7대 교육학 엔진이 자동 적용된 학습 단위" — 마케팅 톤이 본문에 침투. "7대 교육학 엔진"이 무엇인지 설명 없음(jargon).
- "다른 시간표로 전환" — 우측 정렬 링크라 발견성 낮음.

## 8. 접근성 (개략)

- 색대비: primary blue(#2854D8) on white = OK. 회색 메타(#97A0B4) on white 또는 #EDF0F5 배경에서 대비 부족 우려(WCAG AA 미달 가능). 11px·9px의 작은 텍스트가 회색이라 더욱 안 보임.
- 포커스링: CSS 변수 정의되어 있어 키보드 탐색 시 표시될 가능성 높음.
- alt 텍스트: `<img>` 태그 0개 — 모든 아이콘이 SVG 인라인. lucide 류로 보이며 aria-hidden 처리 확인 필요.
- 인풋 0개 — 검색/폼 페이지 확인 필요.
- 터치 타깃: 사이드바 nav 항목 `min-h-11`(44px)로 OK. 하지만 "시작" 작은 뱃지 버튼은 약 24px 높이로 **44px iOS HIG 기준 미달**.

## 9. 모바일/반응형

- **[심각] 헤더~본문 사이 약 250px 빈 공간** — 모바일 첫 화면이 사실상 빈 화면처럼 보임. 가장 시급한 버그.
- 햄버거 메뉴 열림 잘 동작. 메뉴 항목 큰 터치 타깃.
- 하단 탭바 적절. backdrop-blur로 자연스러움.
- 캘린더 시간 라벨(9px)이 모바일에서 더 작아 보임 — 가독성 우려.
- 학습 블록 리스트는 모바일에서 카드 폭 가득 차지, 시각/제목/뱃지/CTA가 한 줄에 끼어들 가능성 — 풀페이지 캡처상 일부 잘림 흔적 있음.

## 10. AI slop 패턴 점검

- 보라/그라데이션 남발: **없음**. 단일 청색 톤. 깔끔.
- 의미 없는 이모지: 컨디션 트래커의 🙂는 명확한 기능. ✨ 같은 장식 이모지 안 보임.
- 가짜 통계/지표: "1.9h / 4.4h", "88%", "64/100" 등 모두 기능적 — slop 아님.
- 글래스모피즘: 헤더 `backdrop-blur` 정도, 절제됨.
- 결론: **AI slop 흔적 거의 없음**. 미니멀·기능 중심으로 잘 잡혀 있음.

## 디자인 토큰

전체 추출 토큰은 `/tmp/pullim-audit/planner/tokens.json` 참조. 요약:

- **Color**: primary 청색 스케일(#EEF3FF→#1D3FA8) + slate 중성 + 시멘틱(success #12B26B / warning #F59E0B / danger #E5484D)
- **Typography**: Pretendard Variable, weight 400/500/600/700, size 9~24px (정리 필요)
- **Radius**: 4 / 10 / 14 / 20 / pill (스케일 정리 권장)
- **Shadow**: xs/sm/md/lg + ring (정의됨, 실사용 적음)
- **Breakpoint**: Tailwind 기본 (640/768/1024/1280/1536)
